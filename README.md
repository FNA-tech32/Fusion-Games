4. **Studio Capabilities & Services**

## 💻 Getting Started & Local Development

### Option 1: Direct Browser Launch (No Build Required)
1. Clone or download this repository:
   ```bash
   git clone https://github.com/your-username/Fusion-Games.git
   ```
2. Open the project folder and double-click [index.html](file:///c:/Users/QBS%20Accounting/Documents/websites/Fusion-Games/index.html) to run the website immediately in any modern web browser.

### Option 2: Local Development with Sass Watch
To edit Sass source files and compile styles automatically:

1. **Install Node.js dependencies:**
   ```bash
   npm install
   ```
2. **Run the Sass compiler watcher:**
   ```bash
   npm run compile:sass
   ```
   This watches all `.scss` files in the `scss/` directory and compiles updates into `assets/css/style.css`.

3. **Serve locally:**
   You can use any local development server (such as VS Code Live Server or `npx serve`):
   ```bash
   npx serve .
   ```

## 🎨 Sass Compilation & Customization

The project uses modular Sass with custom Bootstrap 5 overrides:
- **Theme Variables:** Modify `scss/_custom.scss` to change primary/secondary colors, gradients, and font families.
- **Section Styling:** Customize individual sections located inside `scss/sections/` (`_navbar.scss`, `_intro.scss`, `_services.scss`, `_portfolio.scss`, `_footer.scss`).
- **Icons:** Powered by FontAwesome 6 icons (`fas`, `fab`, `far`) for crisp rendering across all screen resolutions.
